[BloodHound ](https://specterops.io/bloodhound-community-edition/)is an Active Directory auditing tool. It uses graph theory to map the configuration of an AD environment and highlight unintended relationships that can create complex attack paths. It is a tool that should be run periodically - to keep AD secure.

Go here to [install BloodHound](https://support.bloodhoundenterprise.io/hc/en-us/articles/17468450058267-Install-BloodHound-Community-Edition-with-Docker-Compose) - see [their documentation](https://bloodhound.readthedocs.io/en/latest/index.html) for more information. It is free to use in your own environment, or there's the paid version for larger organisations.
